# JEJU:BEFORE 3.5 — 조감 탐색 화면 추가

정적 사이트의 `explore.html`을 열면 관덕정·동문시장·산지천·탑동·용두암·공항 주변의 조감 탐색을 시작합니다. 3D/수직 시점, 확대·축소, 자동 회전, 자동 둘러보기, 32개 장소 검색·팝업·네이버 검색 링크를 제공합니다. `index.html` 원본 관찰·진단 화면 및 `legacy/real.html` 비교용 도보 베타는 보존합니다.

- 기본 배경은 **OSM 윤곽·추정 높이·평면 지형의 비교 화면**입니다. 위성영상이나 사진 측량 모델이 아닙니다.
- `실제 원본 연결`은 전용 Pages 주소에서 본인 키를 직접 입력하는 방식입니다. 공유 CDN에서는 키 입력·연결 요청이 차단됩니다.
- 연결 실패 시 추정 배경으로 자동 전환하지 않습니다. 사용자가 비교 화면을 다시 선택할 수 있습니다.
- 탐색 화면은 조감 전용입니다. 공항을 포함하여 캐릭터 보행은 열지 않습니다.
- 원본 높이·지붕·지형·구축 시점·전체 행정동 범위·실제 출입구는 검증 전입니다.
- 새 브라우저 검사 결과: `precision/explore-browser-result.json`. 이 파일이 현재 커밋을 대상으로 성공한 경우에만 이번 검사 완료로 봅니다. 과거 3.4 기록을 3.5 검사로 재사용하지 않습니다.
